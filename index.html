Project Overview

Proof of concept for an application that calculates how sunny a location is. A creative solution to a specific issue, using the suns location and quite complex math.

Key Features

  • Calculates sun position based on date, time, and geographic coordinates
  • Analyzes sunlight availability at a given location using geometric modeling
  • Processes custom user input for surrounding obstructions (e.g. building height and distance)
  • Outputs time periods during which a location receives direct sunlight

Technical Implementation

The project uses the Pvlib library to calculate the position of the sun at a given time and location. It takes into account the geographical coordinates, altitude, and potential obstructions to sunlight. The script processes user input data, which includes the height and distance of potential sun blockers, and calculates the times when the location is in direct sunlight. Unfortunately, the project is blocked from further development by the fact that Google Earth does not allow for programmatic access to altitude of buildings, which is only available in zones with 3d mode. Therefore it would take a lot of manual work to gather the data needed for the calculations.

Technologies Used

Python Pvlib

🧰 API Generator CLI

Structure of the generated API

Project Overview

A command-line tool that automatically builds Spanner-backed REST APIs with a template OpenAPI schema, reducing API development time by a significant margin through automated code generation.

Key Features

  • OpenAPI schema validation
  • Automatic database schema generation
  • Auto-generated CRUD endpoints and authentication
  • Built-in request validation and error handling
  • Deployment scripts for Google Cloud Run
  • Complete CICD workflows for automated testing, deployment, versioning and linting

Technical Implementation

The CLI tool generates a fully functional REST API by creating a template OpenAPI schema, using user input to require minimal manual input for deployment. It scaffolds a Node.js backend with auto-generated CRUD operations, authentication, and middleware for validation and error handling. Simultaneously, it produces a matching database schema for Google Cloud Spanner, ensuring consistency between the API and data model. The tool streamlines deployment by generating Cloud Run configurations and opening a pull request to the organization’s Terraform GitHub repository, automating infrastructure setup and reducing manual overhead.

Technologies Used

Node.js GCP Spanner OpenAPI Cloud Run

✅/❌ SLA Report Generator

CLI output while running the report generator
Example report using placeholder names and data

Project Overview

A script that evaluates actual performance metrics against service level agreements, and generates a report on it's findings. Automates the data collection, and ensures consistent reporting.

Key Features

  • Evaluates metrics against the actual SLIs
  • Gathers data from different sources for different SLIs
  • Automatic upload to Google Cloud storage
  • Templates to build professional looking documents

Technical Implementation

The CLI tool is built using Node.js and leverages a modular architecture to ensure flexibility and scalability. It reads service level indicators (SLIs) from configuration files and pulls real-time data from various sources using API integrations and custom adapters. Once the data is collected, it evaluates the metrics against predefined thresholds and compiles the results into a structured report using Nunjucks templating. The final reports are exported as PDFs and automatically uploaded to a designated Google Cloud Storage bucket for centralized access and archiving.

Technologies Used

Node.js GCP Nunjucks Google Cloud Storage
